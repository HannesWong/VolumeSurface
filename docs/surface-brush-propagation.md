# 表面笔刷传播核心

## 模块边界

本模块把一次笔刷命中转换为局部表面体素权重场。它不修改原始 density 或 SDF，也不生成显示网格。

输入是一个 Fog Volume 或 Level Set、一个世界坐标笔刷中心、三项笔刷参数和一组全局传播参数。输出只包含与命中点连通且传播距离位于笔刷范围内的表面体素。

## 表面定义

Fog Volume 使用 `value >= isoValue` 表示内部，Level Set 使用 `value <= isoValue` 表示内部。内部体素只要存在一个六邻域外部体素，就作为表面体素参与后续计算。

法线由中心差分梯度得到，并通过 OpenVDB Transform 的逆转置雅可比转换到世界空间。Fog 法线指向低密度侧，Level Set 法线指向正 SDF 侧。

## 平面可信度

每个表面体素在物理半径内收集邻近表面法线，距离权重采用 Gaussian 函数。方向离散程度使用平均合向量长度 `R` 转换：

```text
sigma = sqrt(-2 * log(R))
```

`sigma` 是弧度单位的角度标准差。平面可信度由角度标准差和有效邻居支持量共同连续映射到 `[0, 1]`，不进行平面与非平面的二值分支。

## 传播规则

单点笔刷从距离笔刷中心最近的表面体素开始。连续笔画则先将相邻锚点通过同一张 26 邻域图连接成中心线，再从中心线的全部节点作为零距离源运行有限半径 Dijkstra。边的基础长度使用真实世界距离，因此样例数据的 X/Y 邻接长度为 `0.31 mm`，Z 邻接长度为 `1 mm`。

边代价由三部分组成：

```text
物理长度
+ 平面可信度 × 邻接方向偏离切平面的惩罚
+ 平面可信度 × 相邻法线夹角的惩罚
```

平坦区域会强烈抑制沿法线跳向邻近表面；法线离散区域的约束会连续减弱。没有26邻域路径的候选点不会进入结果。

## 笔刷权重

交互层只需要暴露：

- `coreRadius`：满强度核心半径；
- `falloffRadius`：核心外的过渡宽度；
- `strength`：最大写入值。

核心以内的权重等于 `strength`。过渡区使用 smootherstep 从最大值降到零，核心边界和外边界的一阶、二阶导数均连续。

所有半径都使用 VDB 世界单位。Viewer 使用毫米界面时，需要先把毫米换算为当前 Grid 的世界单位。

## 内存排布

每次笔刷只复制覆盖半径及分析边界所需的局部体素块。块内使用 X 连续的数组分别保存 density、表面标记、法线、平面可信度、角度标准差、传播距离和访问状态。

传播阶段只访问这些连续数组。`maximumCandidateVoxelCount` 用于限制单次笔刷的峰值内存，避免异常半径建立过大的局部块。

## 公共接口

声明位于 `include/volume_surface/SurfaceBrush.h`。入口函数 `propagateSurfaceBrushStroke` 的结果同时包含表面中心线分段和 `SurfaceBrushSample`；每个 sample 包含体素坐标、世界坐标、外法线、角度标准差、平面可信度、传播距离和最终权重。`propagateSurfaceBrush` 是单点入口。

全局算法参数集中在 `SurfacePropagationSettings`，不增加笔刷面板的交互项。

## Viewer 验证

Viewer 使用 Filament 的深度拾取得到 Reference 表面命中位置，不执行 CPU 三角形射线遍历。按住 `Ctrl` 并左键拖动表面时，Viewer 仅记录路径上的表面命中锚点。相邻锚点的最小物理间距为核心半径的一半，且不低于 `0.25 mm`。首个锚点出现约 `120 ms` 后，Viewer 会将当前整条路径连接成表面中心线，并对该中心线进行一次多源扫掠预览；只要路径继续增加，就以同样的节流间隔重新拟合。松开左键会立即补算尚未参与拟合的最后一段。每个表面体素使用到中心线的最短受约束距离计算权重，因此笔画是一次区域拟合，而不是一串独立圆章。

按住 `Ctrl` 时，轨道相机不接收鼠标按下、移动和滚轮事件。鼠标移动会持续发起 GPU 拾取，最近一次 Reference 表面命中点作为笔刷圆心。Filament 场景会显示两个由三角形环带组成的 Renderable；黄色内圈表示核心半径，蓝色外圈表示 falloff 的外边界。环带使用毫米物理尺度，按相机的 right/up 方向每帧更新为正对屏幕的 billboard，并使用关闭深度遮挡的独立材质。

热力图使用独立的透明顶点颜色材质。蓝色表示低权重过渡区，红色表示接近最大强度的核心区域；每次路径拟合和多次单击均以最大值方式累积权重，只有清除按钮会移除已有笔触。GPU 只提交至少包含一个受影响顶点的三角形。

面板显示命中体素、传播样本数、候选体素数、着色顶点数、热力图三角形数、平均平面可信度和 CPU 计算时间。

Brush 面板的 Weight field library 管理已刷的 `surface_weight`，支持保存、加载和同源 VDB 的多个权重场切换。文件约定和未保存修改保护见 [权重场库](weight-field-library.md)。

Brush 面板提供 `Save brush preset` 和 `Load brush preset`。预设文件名为当前工作目录下的 `brush_settings.json`；Viewer 启动时如果文件存在会自动载入其中的全局笔刷参数，保存内容包括核心半径、falloff 半径、强度以及平面和法线传播约束参数。

## 当前限制

当前权重会写入独立的 VDB 权重场并驱动可视化覆盖层，但尚未应用到体数据平滑或网格几何。每次点击仍会重新建立局部块；拖动式连续笔画需要复用或滑动更新该缓存。
