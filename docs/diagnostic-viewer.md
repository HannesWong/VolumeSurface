# 诊断 Viewer 执行文档

## 数据模式

Viewer 明确区分 Fog 与 SDF 两种模式。

Fog 模式显示 `density = isoValue` 的等值面。当前 `rightArm.0224.vdb` 属于该模式，不能把背景值 0 当成几何零值面。

SDF 模式显示具有几何意义的 `φ = 0` 表面。采用内部为负、外部为正的固定符号约定，因此 `φ = -d` 是内缩面，`φ = +d` 是外扩面。

## 第一版职责

第一版负责建立可持续扩展的观察工具，不实现 SDF 转换或平滑算法。

包含以下能力：

- 从指定 FloatGrid 提取 Fog 等值面；
- 使用 Filament 显示三角网格；
- 使用轨道相机观察表面；
- 三维视口采用反向滚轮缩放，并允许调整滚轮缩放倍率；
- 使用球谐环境光提供全局漫反射照明；
- 在诊断面板中调整等值面与网格自适应参数；
- 提供 Reference、Result A、Result B 和 Result C 四个固定结果槽位；
- 为每个槽位保留显示、颜色和透明度状态；
- 在界面中明确标记尚不可用的 SDF 偏移控制。

## 结果槽位

Reference 保存未经平滑的基准表面。

Result A、Result B 与 Result C 预留给不同平滑策略或参数快照。槽位切换只改变可见性，不触发重新计算。

后续后台计算完成后只替换目标槽位对应的 CPU Mesh 与 GPU 资源。

## 切片对照

切片面板支持 XY、XZ 与 YZ 三个方向，并在活动体素包围盒外增加一个背景体素作为轮廓闭合边界。

灰度图显示 FloatGrid 的 density。灰度窗宽独立于几何等值面，可用于检查超过 255 的数值；图像按世界坐标体素尺寸保持物理纵横比。

主轮廓对应 Reference 实际使用的等值面。辅助轮廓固定提供 64、128、192 与 255 四级，并允许分别隐藏。轮廓在 CPU 端栅格化进切片纹理，避免复杂轮廓超过 ImGui 的 16 位索引范围。切片层使用索引坐标选择，同时显示对应世界坐标毫米值。

切片 CPU 数据与 RGBA 图像只在方向、层号、灰度窗宽或主轮廓变化时重建。每一时刻只缓存当前切片，不复制完整稠密体数据。

三维 View 覆盖并清除完整窗口，诊断面板作为不透明 UI 叠加。不能为透明 UI 预留未清除的侧栏区域，否则侧栏空白像素会保留前一帧并产生拖影。

## 线程边界

第一版在界面线程执行网格提取，便于先验证数据语义和渲染接口。

后续耗时的 SDF 和平滑计算进入工作线程。Filament GPU 资源的创建、替换和销毁仍在渲染线程执行，工作线程只产生普通 CPU Mesh。

## 坐标与单位

CPU Mesh 保留 OpenVDB Transform 产生的世界坐标。样例 Transform 使用米，因此界面显示毫米时执行 `m × 1000` 的显示换算，不修改几何数据。

上传到 Filament 时，所有 Mesh 共享由 Reference 包围盒确定的居中与显示缩放，避免不同结果因各自重新居中而产生虚假的对齐效果。

## SDF 扩展接口

SDF 数据可用后，Reference 槽位对应 `φ = 0`。

内缩与外扩观察面作为两个额外诊断层，不占用 Result A、Result B 与 Result C。偏移量使用毫米输入，并换算到 SDF 的世界单位。

该扩展必须在各向同性 SDF 建立后启用。当前各向异性 Fog Volume 不直接执行距离偏移。

## 验证标准

第一版验证以下事项：

- Filament 依赖与核心 Brick Arena 可以独立构建；
- Viewer 能读取样例文件的 `density` Grid；
- 等值面输出只有三角形索引且索引有效；
- 顶点法线有限且完成归一化；
- 无窗口测试能完成 VDB 读取和网格提取；
- 交互程序能够启动并创建 Filament 窗口。
