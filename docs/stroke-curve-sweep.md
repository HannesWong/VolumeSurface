# 表面笔画曲线与扫掠场

## 目标

将 GPU 拾取到的离散锚点转换为贴合 Reference 表面的中心线，并从中心线生成连续的表面权重场。该阶段不修改 density 或生成三维 SDF。

## 中心线构造

每个锚点先映射到局部表面图的最近节点。相邻节点之间以真实世界边长、平面偏移和法线变化组成的连续代价执行路径搜索。所得节点序列连接为中心线；没有连通路径时开始新的中心线分段。

## 表面扫掠

全部中心线节点作为同一次多源传播的零距离源。每个表面节点到中心线的最短受约束距离经过 core 和 falloff 函数转换为权重。该距离场的等值线会在折线拐角形成圆角扫掠边界，而不采用具有 miter 尖角的偏移多边形。

## 后续三维延拓

后续建立 density 等值面的窄带 SDF 后，将表面权重沿 SDF 法线做常值延拓，再乘以深度 falloff。三维延拓必须限制在最近表面映射唯一的安全窄带内。

## 验证

单元测试验证相邻锚点之间的中心线由 26 邻域连续节点构成，并验证多源扫掠仍覆盖每条中心线的所有节点。
